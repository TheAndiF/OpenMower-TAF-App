BL_Align messenger app with bot_v1 and waha_v1 contract
Date: 2026-09-01

Summary:
- Reworked the OpenMower messenger settings client to consume the bot_v1 and waha_v1 MQTT/JSON contract.
- Replaced legacy messenger status/session/QR/group/message/command topics with the documented bot and WAHA snapshot, renew, session, persistent, validation, event and pending-confirmation topics.
- Added schema/version checks, metadata-driven settings editors, local drafts, dynamic flow activation, partial validation handling and 8-second response timeouts.
- Added contract-safe WAHA QR rendering with QR raw-data redaction and no persistent QR storage.
- Added contract-focused controller tests and the qr_flutter dependency.
- Added PDF/DOCX change documentation and a unified patch while keeping the original OpenMower-TAF-App root folder unchanged.
- Static contract checks passed. Flutter/Dart SDK tooling was not available in the execution environment, so flutter pub get, flutter analyze and flutter test still need to be executed before release approval.
